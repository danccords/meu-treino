# Meu Treino

App simples de treino de musculação para o celular, com perfis **Daniel** e **Helo**.

- Treinos A/B (Daniel) e A/B/C (Helo), com desenho e dicas de execução de cada exercício
- Marcar exercícios feitos e o peso usado, e finalizar o treino do dia
- Histórico com editar e excluir
- Trocar ou adicionar exercícios a partir de uma lista com 47 opções
- Backup: os dados ficam salvos no navegador; use **Baixar backup** / **Restaurar backup** na aba Histórico

Acesse pelo GitHub Pages e adicione à tela inicial do celular.
